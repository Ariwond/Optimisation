# Поиск параметров ПИД-регулятора для стабилизации обратного маятника при помощи оптимизации роем частиц

Проект посвящён автоматическому подбору коэффициентов **ПИД-регулятора** для стабилизации обратного маятника на тележке с использованием алгоритма **оптимизации роем частиц (Particle Swarm Optimization, PSO)**.

Вместо ручного подбора коэффициентов `Kp`, `Ki` и `Kd` используется популяция частиц, которая ищет набор параметров, минимизирующий заданную функцию стоимости.

## Описание проекта

Рассматривается классическая задача стабилизации **обратного маятника**, установленного на подвижной тележке.
<img width="665" height="537" alt="image" src="https://github.com/user-attachments/assets/a015d3b7-475c-4fe9-93dc-653b39211f5c" />


Цель управления — удерживать маятник в вертикальном положении:

$$
\theta \rightarrow 0
$$

при этом желательно минимизировать перемещение тележки.

ПИД-регулятор управляет горизонтальной силой, прикладываемой к тележке:

$$
F = -(K_p\theta + K_i\int\theta dt + K_d\omega)
$$

где:

* `Kp` — пропорциональный коэффициент;
* `Ki` — интегральный коэффициент;
* `Kd` — дифференциальный коэффициент;
* `θ` — угол отклонения маятника;
* `ω` — угловая скорость маятника.

Коэффициенты `Kp`, `Ki` и `Kd` подбираются автоматически с помощью PSO.

## Модель системы

Для моделирования используются следующие параметры:

| Параметр | Значение | Описание                     |
| -------- | -------: | ---------------------------- |
| `M`      |    `0.5` | Масса тележки                |
| `m`      |    `0.2` | Масса маятника               |
| `L`      |    `0.3` | Длина маятника               |
| `g`      |   `9.81` | Ускорение свободного падения |
| `F_MAX`  |   `15.0` | Максимальная сила управления |

Состояние системы представляется вектором:

```text
[x, v, θ, ω, ∫θdt]
```

где:

* `x` — положение тележки;
* `v` — скорость тележки;
* `θ` — угол отклонения маятника;
* `ω` — угловая скорость;
* `∫θdt` — интеграл ошибки по углу.

Дифференциальные уравнения системы интегрируются при помощи `scipy.integrate.solve_ivp`.

---

## ПИД-регулятор

Управляющая сила рассчитывается следующим образом:

```python
F = -(kp * theta
      + ki * integral_theta
      + kd * omega)
```

После этого сила ограничивается диапазоном:

```text
-F_MAX ≤ F ≤ F_MAX
```

В проекте используется:

```python
F_MAX = 15.0
```

Ограничение необходимо для моделирования физически ограниченного исполнительного механизма.

## Функция стоимости

Для каждого набора коэффициентов `(Kp, Ki, Kd)` выполняется несколько симуляций с различными начальными углами:

```python
theta_values = [
    -np.pi / 4,
    -np.pi / 8,
     np.pi / 8,
     np.pi / 4
]
```

Таким образом, алгоритм оптимизации ищет регулятор, который работает не только для одного начального состояния.

Для каждой симуляции рассчитывается среднеквадратичная ошибка угла:

$$
MSE_\theta = \frac{1}{N}\sum_{i=1}^{N}\theta_i^2
$$

Также учитывается конечное смещение тележки:

$$
|x_{final}|
$$

Итоговая функция стоимости:

$$
J =
MSE_\theta +
0.1|x_{final}| +
Penalty
$$

Если маятник выходит за пределы:

$$
|\theta| > \frac{\pi}{2}
$$

добавляется штраф:

```python
penalty += 1000
```

Таким образом, алгоритм отдаёт предпочтение параметрам, при которых система остаётся устойчивой и маятник сохраняет положение около вертикали.

## Оптимизация PSO

Для поиска параметров используется алгоритм **Particle Swarm Optimization**.

Каждая частица представляет собой возможный набор коэффициентов:

```text
[Kp, Ki, Kd]
```

Начальные значения генерируются случайным образом в заданных пределах:

```python
LOW_BOUNDS = np.array([0, 0, 0])
HIGH_BOUNDS = np.array([200, 100, 100])
```

То есть:

```text
0 ≤ Kp ≤ 200
0 ≤ Ki ≤ 100
0 ≤ Kd ≤ 100
```

### Параметры PSO

```python
NUM_PARTICLES = 30
NUM_ITERATIONS = 80

W = 0.7
C1 = 1.5
C2 = 1.5
```

где:

* `NUM_PARTICLES` — количество частиц;
* `NUM_ITERATIONS` — количество итераций;
* `W` — коэффициент инерции;
* `C1` — коэффициент индивидуального опыта частицы;
* `C2` — коэффициент влияния лучшего соседа.

### Локальная топология

Вместо использования только глобально лучшего решения каждая частица рассматривает трёх соседей:

```text
левая частица → текущая частица → правая частица
```

И выбирает лучшую из них.

Таким образом, используется локальная топология роя.

Обновление скорости частицы выполняется по формуле:

$$
v_i =
Wv_i +
C_1r_1(p_i-x_i) +
C_2r_2(l_i-x_i)
$$

где:

* `x_i` — текущее положение частицы;
* `v_i` — её скорость;
* `p_i` — лучшее найденное положение этой частицей;
* `l_i` — лучшее решение среди соседей;
* `r1`, `r2` — случайные коэффициенты.

После обновления скорости изменяется положение частицы:

$$
x_i = x_i + v_i
$$

Затем положение ограничивается заданными границами поиска.

## Результаты

После оптимизации строится график:

### Сходимость PSO

Показывает изменение лучшего значения функции стоимости:

```text
Best cost
   │\
   │ \
   │  \____
   │       \____
   │            \___
   └────────────────── Iteration
```

Чем ниже значение `Best cost`, тем лучше найденный набор параметров.

### Динамика системы

Для каждого начального угла строятся четыре графика:

* `x(t)` — положение тележки;
* `v(t)` — скорость тележки;
* `θ(t)` — угол маятника;
* `ω(t)` — угловая скорость.

Основным показателем качества стабилизации является стремление:

$$
\theta(t) \rightarrow 0
$$

## Интерпретация результатов

Хороший набор коэффициентов ПИД-регулятора должен обеспечивать:

* быстрое уменьшение угловой ошибки;
* отсутствие расходимости маятника;
* небольшие колебания около вертикального положения;
* приемлемое перемещение тележки;
* устойчивость при различных начальных отклонениях.

При этом минимальное значение функции стоимости не обязательно означает минимальное перемещение тележки или минимальное время стабилизации. Результат определяется именно той функцией стоимости, которая задана в проекте.

## Возможные улучшения

Проект можно расширить следующими возможностями:

### 1. Учитывать управляющее воздействие

В функцию стоимости можно добавить штраф за большие значения силы:

$$
J = J_\theta + \alpha |x_{final}| + \beta \int F^2dt
$$

Это позволит искать не только устойчивый, но и более экономичный регулятор.

### 2. Учитывать скорость стабилизации

Можно добавить штраф за длительное отклонение маятника от вертикального положения.

### 3. Увеличить количество начальных состояний

Например, тестировать случайные начальные углы:

```python
theta0 = np.random.uniform(
    -np.pi / 4,
    np.pi / 4
)
```

### 4. Сравнить PSO с другими методами

Полученные результаты можно сравнить с:

* ручной настройкой PID;
* методом Ziegler–Nichols;
* генетическим алгоритмом;
* дифференциальной эволюцией;
* Bayesian Optimization.

### 5. Визуализировать движение маятника

Можно добавить анимацию тележки и маятника, чтобы наглядно показать процесс стабилизации.

### 6. Провести серию экспериментов

PSO использует случайную инициализацию частиц, поэтому результаты разных запусков могут отличаться. Для более объективного сравнения можно выполнить несколько запусков с разными `seed` и сравнить полученные значения функции стоимости.
